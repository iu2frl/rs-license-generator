# CMU200 Software Licensing

Notes on the CMU200 software option licensing: where the license file lives, how the keys are encoded, the serial number you need to regenerate them, and how to back everything up.

> **TL;DR** — Back up `C:\CMU\DATA\SWOPT.DAT` before touching anything. Keys cannot be regenerated without the instrument serial number (`NNNNNN/XXX`).

---

## 1. The License File (SWOPT.DAT)

| Item | Value |
|---|---|
| Location | `C:\CMU\DATA\SWOPT.DAT` |
| Format | Plain text, **one 16-character hex line per installed option** |
| Encryption | ARC2 (RC2), key `b"Revision\0"` |
| Regenerable? | Only with the full serial number — otherwise **no** |

Example contents (from a K29-equipped unit, serial `837109/035`):

```

A2AF0325E648F54D
```

## 2. Serial Number

- **Format:** `NNNNNN/XXX` (e.g. `837109/035`, `111264/060`)
- **Where to find it:**
  - On the instrument: **Setup → Options** menu
  - From DOS: `TYPE C:\INTERNAL\LOG\IDENTLTY.DAT`
- **Both parts are needed** for key regeneration:
  - `NNNNNN` — first part, stored as-is
  - `XXX` — second part, stored as a **plain integer with leading zeros dropped** (`035` → `35`)

> ⚠️ Python 2 (and C) interpret a leading `0` as octal — `035` is `29` decimal. Always use the integer value, not the zero-padded string.

---

## 3. Key Format (reverse engineered)

Each line of `SWOPT.DAT` is an ARC2-encrypted 8-byte record:

```
record = struct.pack("<II", serial, serial2 + (option << 20))
```

| Field | Bits | Meaning |
|---|---|---|
| `serial` | 0–31 | First part of serial number (`NNNNNN`) |
| `serial2` | 0–19 | Second part of serial number (`XXX`, leading zeros dropped) |
| `option` | 20–27 | Option number (e.g. 29 for K29) |

Decode an existing key:

```python
from Crypto.Cipher import ARC2
import struct

KEY = b"Revision\0"

for line in open("SWOPT.DAT"):
    if len(line.strip()) == 16:
        a, b = struct.unpack("<II", ARC2.new(KEY, mode=1).decrypt(bytes.fromhex(line.strip())))
        option_num = (b >> 20) & 0xFF
        sn2 = b & 0xFFFFF
        print(f"SN: {a}/{sn2:03d} → K{option_num}")
```

## 4. Generating Keys

Use the included script — it prompts for the serial and prints keys for all known options:

```bash
pip install pycryptodome
python utils/cmuopts.py
# S/N: 123456/035
```

Manual equivalent for a single option:

```python
from Crypto.Cipher import ARC2
from binascii import hexlify
import struct

KEY = b"Revision\0"
serial  = 123456   # first part of serial number (before /)
serial2 = 35       # second part (after /), leading zeros dropped
option  = 29       # K29

record = struct.pack("<II", serial, serial2 + (option << 20))
key = hexlify(ARC2.new(KEY, mode=1).encrypt(record)).decode().upper()
print(key)         # append this line to SWOPT.DAT
```

## 6. Activating a Key

Two ways:

1. **Edit `SWOPT.DAT`** — append the generated hex line, save, restart the instrument.
2. **Via the UI** — **Setup → Options → select option → enter code** directly (no file editing needed).

> Note: enabling an option only unlocks the software — the actual feature files must be installed (e.g. via VersionManager). Community reports: the AMPS module needed the `IS1MV5.20.exe` package installed into a directory named `IS1MV5.20` **after** the matching base package.

---

## 7. Backup / Restore

**Before any modification** (see Phase 0 of the action plan):

```batch
REM On the CMU200 DOS prompt (press F4 at boot)
XCOPY C:\ D:\ /S /E /H
```

Then verify `D:\CMU\DATA\SWOPT.DAT` was copied. Keep it safe — it is the only thing that survives an HDD replacement without the serial number.

## 8. Community Notes (EEVBlog)

From [`EEVBLOG_CMU200.txt`](./EEVBLOG_CMU200.txt):

- **Line length gotcha:** DOS files use `\r\n`, so `len(line) == 17` (Python on Linux) vs `len(line) == 18` (DOS/Linux EOL differences) — strip before checking.
- **Option code pattern:** decrypted records show `0xx0003C` where `xx` is the hex option number (e.g. K29 → `01D0003C`).
- **Key derivation:** the `/XXX` serial part is the low byte of the second word — `836072/060` → `3C` (60 decimal).
- **Activation without file editing:** enter the code directly in Setup → Options.
- **Hardware options vs software options:** B-options (B11, B21, B95…) are hardware; K-options are software licenses in `SWOPT.DAT`.
