# FSP Series License Generation References

This folder contains reference materials and source code related to license generation for the R&S SM series instruments. It includes the original source code, reverse-engineered scripts, and any relevant documentation that can aid in understanding and generating license keys for these instruments.

All information and resources were found at the [EEVBlog forum](https://www.eevblog.com/forum/testgear/enabling-options-for-rs-test-equipment/).

All credits for the original source code and reverse engineering efforts go to the contributors of the [EEVBlog forum](https://www.eevblog.com/forum/testgear/enabling-options-for-rs-test-equipment/).
